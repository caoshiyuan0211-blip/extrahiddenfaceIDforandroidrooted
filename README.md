# FaceLock — 亮屏触控人脸守卫（需 root）

亮屏后，若发生 2 次以上点击/滑动，就后台静默开前摄检测人脸；不是你本人 → 弹出全屏密码锁，按 home / 切后台 / 熄屏再亮都回到锁屏，密码正确才解除。

---

## 一、用 GitHub 云端编译出 APK

1. 新建一个 GitHub 仓库（Private 私有即可）。
2. 解压本 zip，把里面**所有内容**（包括以 `.` 开头的 `.github` 文件夹）传进仓库。
   - 网页上传：进仓库 → Add file → Upload files → 把文件夹内容拖进去 → Commit。
   - 若 `.github` 文件夹网页拖不上去，就单独新建文件 `.github/workflows/build.yml`，内容照抄 zip 里那个。
3. 上传后会**自动开始编译**；也可到仓库 **Actions** 页点进 `build-apk` → Run workflow 手动触发。
4. 等 3–8 分钟，编译成功后：Actions → 点那次运行 → 页面底部 **Artifacts** → 下载 `facelock-debug-apk` → 解压得到 `app-debug.apk`。

> 模型文件（94MB 的 FaceNet）不在仓库里，编译时 GitHub 会自动下载，不用管。

## 二、安装与设置（手机上）

1. 传 APK 到手机，安装（允许未知来源）。
2. 打开 app，授予**相机 + 通知**权限。
3. 输入两遍密码 → **保存密码**。（忘了密码只能重装，务必记牢）
4. **录入 / 重录人脸**：正对前摄，等进度到 `10/10` 自动完成。
5. 点 **启动保护**，按提示依次授予：
   - 「显示在其他应用上层」(悬浮窗)
   - 「忽略电池优化」
   - 首次会弹 **Magisk 授权**（su），选允许，建议设为永久。
6. OxygenOS 还要**手动**放开后台（这些是系统设置，app 改不了）：
   设置 → 电池 → 找到本应用 → 允许后台/自启；设置 → 应用 → 本应用 → 允许自启动。

## 三、测试

- 点 **测试：立刻触发锁定** → 应立刻黑屏锁定。按 home、切后台、熄屏再亮，都应弹回锁屏，输对密码才解锁。
- 实际触发：亮屏后点或滑 **2 次** → 后台静默开前摄（状态栏会**闪一下绿点**）→ 不是你就锁死。

## 四、调参（改 `app/src/main/java/com/jo/facelock/LockState.kt` 顶部常量，改完重新 push 触发编译）

| 常量 | 默认 | 说明 |
|---|---|---|
| `MATCH_THRESHOLD` | 0.68 | 人脸相似度门槛。老误锁你自己 → 调低(如 0.60)；放进陌生人 → 调高 |
| `TRIGGER_TOUCH_COUNT` | 2 | 亮屏后几次触控触发检测 |
| `CHECK_WINDOW_MS` | 4000 | 找脸的时间窗(毫秒) |
| `LOCK_ON_NO_MATCH` | true | 窗口内没找到匹配的脸就锁。设 false 则只有"认出是别人"才锁 |

## 五、已知局限（先说清）

- **绿点**：安卓 12+ 开摄像头状态栏必有绿点，没法完全隐形（要压掉得再上 Xposed）。
- **逃逸**：对普通小偷够用；但懂电脑的人用安全模式 / adb / recovery 仍能卸载。
- **首次编译可能报错**（没真机编译过）。报错就把 Actions 里红色那步的日志复制发我，我来修。
